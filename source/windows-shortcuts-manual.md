# Windows 快捷键与 F 键图标速查手册

本手册汇总笔记本 F 键功能图标与 Windows 系统快捷键，按场景分类整理，方便快速查阅。适用于 Win10 / Win11 系统。

# 一、F 键图标对照表

**核心原则：认准图标，而不是 F 数字。**不同品牌把同一功能放在不同 F 位（如触摸板可能是 F6、F8、F9），只有图标是统一的。以你键盘上实际印刷的图标为准。

|图标|含义|说明|
|---|---|---|
|☀ 太阳向下|屏幕变暗|降低屏幕亮度|
|☀ 太阳向上|屏幕变亮|提高屏幕亮度|
|喇叭 \+ 斜杠|静音|一键关闭声音|
|喇叭 \+ 减少波纹|音量减小|调低音量|
|喇叭 \+ 增多波纹|音量增大|调高音量|
|🖱 触摸板方框|**触摸板开关**|你的电脑触摸板图标在 F8，误触关闭后按 Fn\+F8 恢复|
|显示器方框重叠|投屏切换|复制、扩展、仅第二屏等投影模式（同 Win\+P）|
|麦克风 \+ 斜杠|关闭麦克风|开会静音麦克风|
|飞机 ✈|飞行模式|同时关闭 Wi\-Fi、蓝牙等无线连接|
|摄像机 \+ 斜杠|关闭摄像头|一键遮挡并禁用摄像头|
|键盘发光线条|键盘背光|开关或循环调节背光亮度|
|▶⏸|播放 / 暂停|控制媒体播放|
|⏮ / ⏭|上一曲 / 下一曲|切换音视频曲目|
|月亮 / Zz|睡眠|息屏进入待机|
|锁头 🔒|锁屏|锁定系统|
|电池 \+ 风扇|性能模式|在安静 / 均衡 / 狂暴等模式间切换|
|方框 \+ 剪刀|截图|快捷截图|

## Windows 原生 F 键功能

以下为不带图标的 F 键原生功能，Windows 通用：

|按键|功能|
|---|---|
|F1|帮助|
|F2|选中文件重命名|
|F3|搜索|
|F5|网页 / 文件夹刷新|
|F6|切换页面光标位置|
|F11|浏览器全屏|
|F12|浏览器开发者工具|

**Fn 锁（Fn \+ Esc）：**打开后，直接按 F8 即可开关触摸板，无需一直按住 Fn；关闭时需按 Fn \+ F8。
